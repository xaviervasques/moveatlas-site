Citation
========

The MoveAtlas resource paper is in preparation; a versioned software DOI
(Zenodo) will be minted at the public launch and listed here.

How to cite today
-----------------

Three rules, in force from the first use:

1. **Always cite the source dataset papers** of every dataset you use.
   Every data card carries its publications with ready BibTeX (use the
   copy button on any code block).
2. **Cite the MoveAtlas corpus** when you use its harmonized records. One
   record, with its own DOI, stands for the whole release and links to the
   54 dataset records
   (`10.5281/zenodo.22810708 <https://doi.org/10.5281/zenodo.22810708>`__);
   each dataset page gives the DOI of its own record:

.. code-block:: bibtex

   @misc{moveatlas_corpus,
     author    = {Vasques, Xavier},
     title     = {MoveAtlas harmonized corpus, release 1},
     version   = {1.0},
     year      = {2026},
     publisher = {Zenodo},
     doi       = {10.5281/zenodo.22810708},
   }

3. **Cite the MoveAtlas software** by name and version until the DOI
   exists:

.. code-block:: bibtex

   @software{moveatlas,
     author  = {Vasques, Xavier},
     title   = {MoveAtlas: the open atlas of movement data, human and animal},
     version = {0.1.0.dev0},
     year    = {2026},
     note    = {Versioned DOI minted at the public launch},
   }

APA style:

.. code-block:: text

   Vasques, X. (2026). MoveAtlas harmonized corpus, release 1
   (Version 1.0) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.22810708

   Vasques, X. (2026). MoveAtlas: The open atlas of movement data,
   human and animal (Version 0.1.0.dev0) [Computer software].

Published with MoveAtlas?
-------------------------

From the public launch, a "Papers using MoveAtlas" list lives on this
page: open an issue on the repository to have your paper added. Until
then, send them to the Institut du Neurone team.
