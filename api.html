API#

Registry#

The dataset registry: one row per catalogued dataset.

Single source of truth is the repository’s generated index (docs/datasets_index.csv + docs/license_matrix.csv, both emitted by gen_datacards.py). Resolution order for the CSVs:

  1. $MOVEATLAS_REPO/docs/ when the env var is set;

  2. the repository docs/ next to an editable install (../docs from here);

  3. the snapshot bundled as package data (moveatlas/data/), refreshed by the release pipeline.

The registry does not open any data file; it only serves metadata and the access-case classification that datasets/base.py enforces.

moveatlas.registry.snapshot_info()[source]#

Provenance of the registry snapshot bundled as package data (moveatlas/data/SNAPSHOT.json: generated_at, datasets_index_rows, license_matrix_rows, source). Returns {} when the file is absent. This describes the bundled copy only; the registry itself may be reading docs/ instead (see _docs_dir).

moveatlas.registry.records_table()[source]#

dataset id -> {“record”: zenodo record id, “doi”: …}: the published MoveAtlas records, shipped with the package (moveatlas/data/zenodo_records.json, written by build_records_table.py). {} when the file is absent. Read once per process.

moveatlas.registry.access_case(row)[source]#

Classify a registry row into the four access cases.

  • hosted: redistribution allowed, our record store serves it.

  • local_only: private-tier data on disk (empty since 2026-09-01: the CODY derived release went public on Zenodo and the cody ids classify as hosted; raw patient video stays in-house, outside the atlas).

  • barrier: a documented access barrier (no automated route).

  • recipe: everything else (fetch from origin + local ingestion).

moveatlas.registry.list_datasets(family=None, case=None)[source]#

Return registry rows (dicts), optionally filtered by family or access case. Each row gains an ‘access_case’ key.

moveatlas.registry.dataset_info(code)[source]#

The registry row for one dataset id, or raise with the known ids.

Datasets#

Base dataset classes: identity, access-case enforcement, data access.

A MoveAtlas dataset is ONE identity (one code, one card, one DOI, one download) however many modality streams it carries. get_data() returns (records, metadata): records are dicts in the canonical contract of their family (configs/canonical_*.yaml); metadata is a pandas DataFrame with at least [dataset, subject_ns, task, modality, n_frames, fps], the contract with the evaluation layer.

exception moveatlas.datasets.base.AccessError[source]#

Raised when a dataset’s access case forbids automated download.

class moveatlas.datasets.base.BaseDataset[source]#

Subclasses set code and implement _load(store, subjects, modality) returning (records, metadata_rows).

files()[source]#

Store-relative paths of every file this dataset holds: what is on this machine under its registry path, plus, for a hosted dataset, what its published record lists (nothing is downloaded to list). Many hosted records hold tables, archives or documents rather than canonical records; this is how you see them.

path(name)[source]#

A local path to one of the dataset’s files, by file name or store-relative path: served from this machine when it is there, else downloaded from the published record and sha256-verified. Read a table with pandas, an archive with zipfile, an .npz container with moveatlas.records.load().

get_data(subjects=None, modality=None)[source]#

Return (records, metadata). subjects filters on subject_ns; modality filters multimodal datasets to one stream.

moveatlas.datasets.base.recipe_of(info)[source]#

The ingestion script the registry row names (access, then status), with its flags when they follow it; a pointer to the card otherwise.

class moveatlas.datasets.base.GenericDataset(code)[source]#

Registry-backed adapter for every catalogued id without a dedicated class. Hosted and recipe ids load from whatever their ingestion left under <path>/processed/ (moveatlas.datasets.generic); asking a barrier id for bytes raises the documented route instead of pretending, and a recipe id nothing ingested says which script to run.

property modalities#

The modalities found on disk (or in the published record), computed once; () for barrier / local_only ids and when nothing is ingested.

moveatlas.datasets.base.load_record(path)[source]#

Read a record container: the moveatlas-record/1 .npz natively; a legacy .pkl through the transition reader (DeprecationWarning). The .npz sibling of a .pkl path wins when it exists.

PhysioNet gaitpdb adapter (gait in Parkinson, VGRF insoles).

Vertical ground-reaction forces from 8 insole sensors + the per-foot total at 100 Hz, three studies pooled by PhysioNet (Ga/Ju/Si prefixes). The cohort is encoded in the subject id by the SOURCE itself: ‘Co’ = control, ‘Pt’ = Parkinson patient; the adapter exposes it as an eval-only ‘group’ the honest way (read from the id, documented, never guessed from the signal).

Full-body Plug-in Gait mocap at native 100 Hz, mapped to the canonical 15-joint skeleton by measured geometry (configs pig_vancriekinge). Every record carries the eval-only cohort label (1 stroke, 0 able-bodied) and its group attribute; 737 records / 188 subjects since the 2026-08-28 prefixed-labels recovery.

class moveatlas.datasets.stroke_gait.StrokeGaitVanCriekinge[source]#

CODY adapter: the program’s own hyperkinetic cohort (hosted tier).

Raw patient video NEVER leaves the machine (owner mandate, docs/PRIVACY_GATE.md); what this adapter reads is the canonical 2D-pose derivative already ingested from cody_3, the canonical source for the adult labeled cohort. Labels ride on the records and are EVAL-ONLY (standing rule R1: never pretraining).

The publishable derived data is PUBLIC since 2026-09-01: the CODY Zenodo deposit (concept DOI 10.5281/zenodo.22232609, CC BY 4.0), fetched and md5-verified by fetch_cody_zenodo.py at the repo root. That flipped the cody ids from local_only to hosted. This class stays the local, full-cohort canonical view; a machine without the local records fetches the deposit and runs the ingestion recipe.

Recipes: fetch and ingest#

The recipe tier as library calls: fetch a dataset from its origin host, harmonize it into the store, then moveatlas.dataset(id).get_data().

import moveatlas moveatlas.fetch(“fog_turning_filho”) # origin download, journaled moveatlas.ingest(“fog_turning_filho”) # canonical records in the store recs, meta = moveatlas.dataset(“fog_turning_filho”).get_data()

A recipe is one of three things, and moveatlas.recipe(id) says which:

  • LIBRARY: both steps run in Python from this package (the transports in moveatlas.recipes.transports, the contract writers such as moveatlas.recipes.imu). What a stranger can do from a pip install.

  • SCRIPT: the dataset was harmonized by a repository script that is not ported yet; fetch()/ingest() raise RecipeIsScript naming the exact commands to run from a clone of the repository. Honest, not silent.

  • NONE: hosted datasets need no recipe (they download from their MoveAtlas record); barrier datasets have a documented route instead.

The store both steps write to is moveatlas.store._repo_root(): the developer’s checkout when MOVEATLAS_REPO points at it, the source tree when the package sits in one, else ~/.moveatlas/store (MOVEATLAS_STORE).

moveatlas.recipes.fetch(id, root=None)[source]#

Download id from its origin host into the store’s raw/ directory (resumable, checksums journaled). Returns what the transport reports.

moveatlas.recipes.ingest(id, root=None)[source]#

Harmonize the fetched raw files of id into canonical records in the store. Returns (output path, number of records).

moveatlas.recipes.recipe(id)[source]#

The Recipe for id, or raise NoRecipe with the reason.

moveatlas.recipes.store_root()[source]#

The directory whose datasets/ tree fetch() and ingest() fill and LocalStore serves (see the module doc).

exception moveatlas.recipes.RecipeIsScript[source]#

The recipe exists only as repository scripts; the message names them.

exception moveatlas.recipes.NoRecipe[source]#

The dataset needs no recipe (hosted or barrier) or is unknown.

class moveatlas.recipes.Recipe(id, fetch_fn=None, ingest_fn=None, fetch_cmd=None, ingest_cmd=None, notes='')[source]#

One dataset’s recipe. fetch_fn(root) and ingest_fn(root) are library implementations; fetch_cmd / ingest_cmd are the repository commands for a script recipe; notes is what a user must know first (an account, a licence condition, a size).

Origin-host transports for the recipe tier: download into the store’s raw/ directory, resumable, verified, journaled.

Every transport writes under <root>/datasets/<family>/<id>/raw/ and appends one line per completed file to downloads.sha256 beside raw/ (the format every dataset directory of the repository already uses: <sha256> <name> <bytes>). A file already present with the expected size and checksum is not downloaded again, so a fetch can be re-run.

Nothing here needs more than the standard library, except the figshare transport which shells out to curl: ndownloader.figshare.com answers python’s TLS stack with empty 202 bodies and curl’s with the file (established 2026-08-26, see tools/fetch/fetch_figshare_curl.py in the public tree for the full account). curl ships with macOS and Windows 10+ and is a package away on Linux.

exception moveatlas.recipes.transports.FetchError[source]#

A transfer that could not be completed or verified.

exception moveatlas.recipes.transports.ManualDownload(url, dest, size=None, md5=None)[source]#

The host answers clients with a browser challenge: the file must be saved by hand. The message says which URL, into which path, and what size and checksum the file must have; fetch() then accepts the file it finds there (verified) and ingest() proceeds.

moveatlas.recipes.transports.download_url(url, dest, size=None, md5=None, tries=6)[source]#

Resumable urllib download to dest (via dest.part), verified against size and md5 when given. Returns (bytes, sha256).

moveatlas.recipes.transports.figshare_article(root, path, article_id, only=None, skip=None)[source]#

Fetch the files of a public figshare article into <root>/<path>/raw. only keeps the named files; skip drops the named ones (a way to leave a 5 GB video archive the atlas never ingests where it is). Returns the list of (name, bytes, sha256) fetched or already there.

moveatlas.recipes.transports.zenodo_record(root, path, record_id, only=None, skip=None)[source]#

Fetch the files of a public Zenodo record into <root>/<path>/raw, checksums verified against the record’s own manifest.

moveatlas.recipes.transports.urls(root, path, named_urls)[source]#

Fetch plain URLs into <root>/<path>/raw: named_urls is {file name: url}. No checksum is known in advance; the journal records what arrived.

The canonical IMU contract (configs/canonical_imu.yaml) as a library: the record maker and the writer, ported from the repository’s build_canonical_imu.py so a recipe can harmonize into a user store.

Only what the library recipes need is here; the repository builder keeps every dataset mapping and stays the provenance record. The two must agree on the record shape: signal (T, L, 9) float32 in g / deg/s / uT, location_ids, channel_mask (L, 9), sample_valid (T, L), fps, subject_ns, task, source, n_frames, and dropout_fraction when a sample is invalid.

moveatlas.recipes.imu.make_record(loc_data, fps, subject_ns, task, source, label=None)[source]#

loc_data: {location_name: {channel_name: np.array(T,)}}, same T for all. Three validity rules hold for every source (2026-08-23): a channel with no finite sample anywhere is an ABSENT sensor, masked off and zeroed; a location left with no valid channel is dropped; a channel that drops out for a stretch stays present, its non-finite samples zeroed and the record gains sample_valid (T, L). The signal is therefore finite and nothing is inferred.

moveatlas.recipes.imu.save(root, source, recs, path=None)[source]#

Write the records as <root>/<path>/processed/canonical_imu.npz (moveatlas-record/1), path defaulting to datasets/imu/<source>, the dataset’s registry path, which is where the generic loader looks. Merge the per-record rows into <root>/datasets/_canonical_imu_manifest.csv when that central manifest exists (an ingestion machine); a user store gets the rows in processed/manifest.csv instead. Returns the output path.

Frames and visualization#

Records as pandas DataFrames.

to_frame(record) turns any canonical record into a tidy, time-indexed DataFrame with NAMED columns, so a researcher can .head(), .describe(), resample, merge and plot with the pandas they already know. The masks are honored the honest way: whatever a mask marks invalid becomes NaN in the frame, never a silent zero.

Column layout per family:

pose        MultiIndex (joint, axis['x','y','z'])
emg / eeg   channel names (muscle_side for EMG, site for EEG)
imu         MultiIndex (location, channel) for instrumented slots only
force       MultiIndex (foot['left','right'], sensor['s1'..'s8','total'])
silhouette  the 8 per-frame scalar descriptors (undetected frames NaN)

The index is time in seconds at the record’s native rate.

moveatlas.frames.to_frame(rec)[source]#

Canonical record -> tidy time-indexed DataFrame (see module doc).

One-liner plotters for canonical objects (the nilearn pattern: each domain object gets a sensible-defaults visualizer):

plot_skeleton(rec, frame, ax=None)   one pose frame as a stick figure
plot_trace(rec, n_channels=6, ...)   any signal-bearing record, stacked

Both return the matplotlib Axes so callers can keep styling.

moveatlas.viz.plot_skeleton(rec, frame=0, ax=None, color='#2a78d6', axes=(1, 2))[source]#

Draw one frame of a canonical pose record; masked joints stay absent (never invented).

moveatlas.viz.plot_trace(rec, n_channels=6, t_start=0.0, t_stop=10.0, ax=None, color='#2a78d6')[source]#

Stacked-trace view of any signal-bearing record (emg/eeg/imu/ force), first n channels, mean-centered with per-channel offsets.

Paradigms#

FixedIntervalWindows: the first concrete paradigm.

A paradigm defines what a valid SAMPLE is, independently of any dataset (the MOABB transposition). This one cuts continuous canonical records into fixed-duration windows at each record’s NATIVE rate (no resampling, per the contracts), and returns the (X, y, groups, meta) quadruple that evaluations consume. Windows inherit their record’s subject_ns as group, so patient-level splits stay leak-free by construction.

Label sources are explicit, never guessed: label_from=”record” reads rec[“label”] (eval-only labels riding on the record, e.g. stroke vs able-bodied); label_from=”task_prefix” derives the class from the task name stripped of its trial suffix (e.g. gait120’s 7 locomotion tasks).

Evaluations#

Patient-level split primitives (pure numpy, no sklearn dependency).

moveatlas.evaluations.splits.cross_patient_folds(metadata, n_splits=5, seed=0)[source]#

Yield (train_idx, test_idx) over metadata rows, grouped by subject_ns so no subject straddles a fold. Deterministic under seed.

CrossPatientEvaluation: the first concrete evaluation.

Folds are patient-level (a subject never straddles a split); the score is balanced accuracy, robust to the class imbalance most clinical datasets carry (e.g. 50 stroke vs 138 able-bodied). Per-fold scores are returned so the analysis layer can meta-analyze; nothing is pooled across datasets here by design.

scikit-learn is an optional dependency (the bench extra): it is imported when evaluate runs, not when the module loads.

Pipelines#

Statistical feature baselines (the LogVariance+LDA tradition MOABB’s 2024 study showed is still a hard floor to beat).

scikit-learn is an optional dependency (the bench extra). The module imports without it: StatFeatures falls back to plain-object bases and baseline_pipelines() raises an informative ImportError.

class moveatlas.pipelines.features.StatFeatures[source]#

Per-channel summary statistics over each window: log-variance, RMS, mean absolute delta (a crude velocity), range. NaN-safe: the pose contract encodes missing joints as zeros with masks, and IMU dropouts as zeros, so plain stats stay finite.

moveatlas.pipelines.features.baseline_pipelines()[source]#

The v0 pipeline set: a chance reference and two classic floors.

Store#

The MoveAtlas record store: where harmonized canonical records live.

Three stores, one interface (path / glob_dir / list_dir / verify_manifest):

  • LocalStore: the repository’s datasets/ tree (the ingestion machine).

  • RemoteStore: MoveAtlas’s own Zenodo records, downloaded on demand into a local cache (~/.moveatlas/records or MOVEATLAS_CACHE) and sha256-verified against each record’s files.csv manifest. Downloads resume from a .part file (Range requests), retry with backoff on transient errors, print a progress line for large files, and turn “no network” into OfflineError.

  • HybridStore: local first, remote second, returned by open_store() when this machine has a repository AND the release ships a records table; a relpath absent locally is fetched from the dataset’s record when one exists (docs/MoveAtlas_PLATFORM_DESIGN.md section 8: one click, one pip).

sha256 discipline: verify_manifest() checks record files against a manifest CSV (path,sha256). Manifests are produced at release-assembly time; local reads skip verification unless a manifest exists.

Environment: MOVEATLAS_REPO (repository root), MOVEATLAS_CACHE (download cache), MOVEATLAS_QUIET=1 (no progress or retry lines on stderr).

exception moveatlas.store.OfflineError[source]#

A record is not in the local cache and the network is unreachable (urllib URLError after the retries). Subclasses FileNotFoundError so callers that already handle “not here” keep working.

moveatlas.store.user_store_root()[source]#

The per-user store a pip-installed package writes to: $MOVEATLAS_STORE, else ~/.moveatlas/store. It holds a datasets/ tree laid out exactly like the repository’s, so every recipe writes to datasets/<family>/<id>/{raw,processed}/ there and LocalStore serves it.

class moveatlas.store.RemoteStore(cache=None, api_base='https://zenodo.org/api', table=None)[source]#

The Zenodo record store: downloads record files on demand into a local cache (~/.moveatlas/records or MOVEATLAS_CACHE) and verifies every byte against the record’s own files.csv manifest (sha256).

Two record layouts, both produced by upload_zenodo.py:

  • direct: one record file per store file, flat name = path with ‘/’ replaced by ‘__’; manifest columns path,bytes,sha256,record_name.

  • bundled (>100-file datasets): ZIP parts; manifest columns path,bytes,sha256,zip_part[,zip_part_sha256]; members keep their true relpath. When zip_part_sha256 is present the part is verified before any extraction (once per process for cached parts).

Transport: an interrupted download leaves <dest>.part and the next call resumes it with a Range header (a server that ignores the range restarts the file). Transient failures (URLError, HTTP 429 and 5xx) are retried RETRIES times with BACKOFF seconds between tries; 404 and other client errors raise at once. A URLError that survives the retries becomes OfflineError (a FileNotFoundError).

An unpublished (still-draft) record answers 404 on the public API: the error says so honestly instead of guessing.

has_record(relpath_or_id)[source]#

list_dir(reldir)[source]#

moveatlas.store.open_store()[source]#
